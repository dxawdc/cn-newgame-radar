# 游戏详情性能优化发布记录

2026-10-12 北京时间约 14:02，第一批优化已上线。

## 改动

- 新旧详情接口均按产品定向读取。只解析本款游戏的渠道记录、查询关联图片缓存，不进入全库目录加载锁。
- 旧整数 ID 逐跳定向查询，保留合并跳转的环检测和长度限制；UUID 合并跳转保持原有语义。
- 产品身份、成员、图片记录使用同一个只读事务快照，避免读取时与目录重建交错。
- 前端复用被点击卡片的基本资料，先显示名称、图标、开发商和简介，随后补全完整档案。
- 请求支持取消、15 秒超时、错误提示和重试；通过请求身份校验，阻止旧响应覆盖新详情或关闭后的页面。
- 更新静态资源版本号，确保刷新页面后获取新版脚本与样式。

本批没有引入详情缓存，也没有改写事件、介绍及图集选择规则。列表、统计、日历轻量化和图集尺寸预留属于原方案后续批次。

## 验证

- 全套 Python 测试：175 项通过；JavaScript 语法检查通过。
- 本地现有 5,744 款产品逐一比对，新旧公开详情和介绍内容全部一致。
- 服务器发布前抽取 20 款游戏，覆盖不同来源和复杂成员结构，定向查询与原目录实现返回内容一致。
- 浏览器模拟验证：即时预览、A/B 快速切换、关闭后的晚返回、503 后重试、产品不存在和超时恢复均通过，页面脚本错误为 0。移动端抽屉宽度检查通过。
- 线上实际打开“粒粒的小人国”，名称、介绍、图集及关注按钮正常，加载的脚本版本为 `20261012-detail-fast`；浏览器记录详情请求约 31.4 毫秒。

## 发布后 HTTP 抽测

从本机到线上地址，匿名访问 20 款产品，每款 5 次，共 100 次；请求串行，间隔 40 毫秒，客户端复用连接。每次都检查返回内容与发布前服务器基线一致。

| 指标 | 结果 |
| --- | ---: |
| 中位耗时 | 29.49 毫秒 |
| P95 | 35.65 毫秒 |
| 最快 / 最慢 | 26.40 / 46.21 毫秒 |
| 第一轮中位耗时 | 29.80 毫秒 |
| 内容一致性 | 100 / 100 |

实施前，三款游戏共五次串行 HTTP 抽测约 2.0～3.1 秒；第一批已经消除主要全库处理开销。前后样本数量和连接条件不同，上述结果是本次环境下的验收抽样，不是长期线上 SLO 或严格压力测试。

受控并发试验中，先启动统计请求，100 毫秒后发起详情请求：统计耗时约 4,023 毫秒，详情仅约 77.65 毫秒，表明详情不再等待统计的全库目录加载。统计本身的耗时仍属于后续优化范围。
