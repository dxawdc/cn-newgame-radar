1. 数据入库默认不再执行媒体补齐；媒体独立运行、单并发，每日 09:30 错峰执行，失败不否定数据发布结果。

3. 入库与媒体、日常采集共用文件锁，避免重任务重叠；为服务设置内存、CPU、I/O 权重与时间限制。入库内存上限 512 MiB、媒体 384 MiB，网站 512 MiB。

6. 本机运行脚本与受版本控制的 `scripts/run_simulator_daily.example.ps1` 同步更新。实际运行脚本仍按项目原约定被 Git 忽略。
